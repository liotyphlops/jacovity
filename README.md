# Jacovity

> El proyecto dedicado a documentar, analizar y distribuir mierda sobre Jacob.

## ¿Qué es Jacovity?

**Jacovity** es un proyecto de código abierto creado con un único propósito:

**Tirarle mierda a Jacob.**

Aquí se recopilan herramientas, funciones y recursos necesarios para llevar a cabo esta noble labor de manera organizada y profesional.

## Características

* Insultos automatizados.
* Generación de mierda dirigida a Jacob.
* Sistema avanzado de recopilación de momentos cuestionables.
* Documentación de las atrocidades cometidas por Jacob.
* Soporte para cantidades ilimitadas de hate.
* 100% impulsado por la necesidad de molestar a Jacob.

## Instalación

```bash
git clone https://github.com/tu-usuario/jacovity.git
cd jacovity
```

Instala las dependencias necesarias y ejecuta el proyecto.

## Uso

```text
> /jacovity jacob
> Analizando a Jacob...

> Generando respuesta...
```
